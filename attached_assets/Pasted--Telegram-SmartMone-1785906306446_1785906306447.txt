Создай полноценную профессиональную платформу для трейдинга с Telegram-ботом под названием SmartMoney AI.

Главная цель проекта — искать только сделки высокой вероятности на основе концепции Smart Money Concepts (SMC). Бот не должен пытаться предсказывать рынок, он должен ждать появления объективных подтверждений и только после этого отправлять сигнал.

=========================================================
ОСНОВНАЯ ИДЕЯ
=========================================================

Основная стратегия строится вокруг:

• Smart Money Concepts (SMC)
• Накопления (Accumulation)
• Пробоя уровня
• Подтверждения объемом
• Подтверждения старшим таймфреймом

Никаких случайных сигналов.

Сигнал появляется только после совпадения нескольких факторов.

=========================================================
СТРАТЕГИЯ
=========================================================

Бот должен автоматически определять:

1. Break Of Structure (BOS)

Определять:
- Bullish BOS
- Bearish BOS

2. Change Of Character (CHoCH)

Определять:
- Bullish CHoCH
- Bearish CHoCH

CHoCH использовать как ранний признак смены тренда.

3. Liquidity

Находить:

- Equal High
- Equal Low
- Swing High
- Swing Low
- Liquidity Grab
- Stop Hunt

Определять где находится ликвидность.

4. Order Blocks

Находить:

Bullish Order Block

Bearish Order Block

Показывать силу каждого блока.

5. Fair Value Gap

Определять:

• новый FVG

• заполненный FVG

• частично заполненный

• полностью заполненный

=========================================================
ГЛАВНЫЙ МОДУЛЬ — НАКОПЛЕНИЕ
=========================================================

Это самый важный модуль.

Бот должен автоматически искать накопление.

Использовать признаки:

• снижение ATR

• уменьшение волатильности

• сжатие диапазона

• большое количество внутренних свечей

• большое количество тестов уровня

• рост объема внутри диапазона

• отсутствие сильного продолжения движения

• удержание диапазона длительное время

• сужение диапазона Bollinger Bands

Каждое накопление должно получать оценку:

Weak

Medium

Strong

Extreme

Чем сильнее накопление, тем выше рейтинг будущего сигнала.

=========================================================
МАШИННОЕ ОБУЧЕНИЕ
=========================================================

После каждой закрытой сделки бот должен сохранять результат.

Если определенный сетап показывает высокий Win Rate —

автоматически увеличивать его рейтинг.

Если эффективность ухудшается —

уменьшать рейтинг.

Таким образом бот постепенно адаптируется под текущий рынок.

=========================================================
ИНТЕРФЕЙС
=========================================================

Интерфейс должен выглядеть современно и профессионально.

Использовать:

• красивые карточки сигналов

• эмодзи

• цветовую индикацию LONG/SHORT

• изображения графиков

• автоматическое построение уровней

• отображение Order Blocks

• отображение BOS

• отображение CHoCH

• отображение Liquidity

• отображение FVG

• отображение зон накопления

После генерации сигнала бот должен автоматически строить график с нанесенными уровнями, точкой входа, Stop Loss, Take Profit, Order Block, FVG, зоной накопления и пояснением, почему был найден именно этот сетап.

Код должен быть написан по принципам Clean Architecture, быть модульным, масштабируемым, асинхронным и готовым к дальнейшему развитию. Каждый модуль (SMC, накопление, объем, сигналы, Telegram, аналитика, статистика) должен быть независимым. Проект должен быть готов к деплою через Docker и иметь понятную структуру файлов, документацию и комментарии.
